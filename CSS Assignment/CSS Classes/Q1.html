CSS Pseudo-Classes Demonstration

Interactive examples of :hover, :focus, :active, and :nth-child()

:hover

Triggers when the mouse pointer passes over an element. Changes background and scales up slightly.

:focus

Triggers when an element gains focus (e.g., keyboard tab or click). Displays a blue border outline.

:active

Triggers while an element is being activated/pressed down by the user.
