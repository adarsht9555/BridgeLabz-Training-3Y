CSS Box-Sizing Comparison

Demonstrating how content-box vs border-box affects rendered width

box-sizing: content-box

Specified Width: 300px
+ Padding: 30px (x2)
+ Border: 10px (x2)
= Total Width: 380px

Padding and borders are added outside the declared width, causing the box to expand beyond 300px.

box-sizing: border-box

Specified Width: 300px
+ Padding: 30px (x2)
+ Border: 10px (x2)
= Total Width: 300px

Padding and borders are absorbed inside the declared width, maintaining an exact total width of 300px.
